# Streamlit 로또 번호 생성기 🎰

파이썬 초보자도 쉽게 이해하고 활용할 수 있도록 `Streamlit`과 `Session State`를 활용해 만든 로또 번호 생성기 웹 애플리케이션입니다.

## 🛠️ 주요 기능

* **로또 번호 생성**: `1`부터 `45` 사이의 숫자 중 중복 없는 `6`개의 번호를 무작위로 추출하여 오름차순으로 정렬합니다.
* **최대 5세트 유지**: 버튼을 계속 누르더라도 최근 생성된 최대 `5`개의 로또 번호 세트만 화면에 유지되도록 관리합니다.
* **실제 로또 공 색상 반영**: 한국 로또 공식 색상 규칙에 따라 번호대별로 색상이 다르게 표시됩니다.
  * `1 ~ 10`: 노란색 🟡
  * `11 ~ 20`: 파란색 🔵
  * `21 ~ 30`: 빨간색 🔴
  * `31 ~ 40`: 회색 ⚫
  * `41 ~ 45`: 초록색 🟢
* **파일 내보내기**: 생성된 로또 번호 목록을 텍스트 파일(`my_lotto_numbers.txt`)로 손쉽게 다운로드할 수 있습니다.

## 🚀 실행 방법

### 1. 패키지 설치
프로그램 실행에 필요한 라이브러리(`streamlit`)를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
터미널에 아래 명령어를 입력하여 Streamlit 앱을 실행합니다.
```bash
streamlit run lotto_generator.py
```
